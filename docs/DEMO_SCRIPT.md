# Five-minute demo script

| Time      | Action                                                                                 |
| --------- | -------------------------------------------------------------------------------------- |
| 0:00–0:25 | State the stale-knowledge problem and show the baseline.                               |
| 0:25–1:10 | Launch the disclosed prepared source-version run and reveal the three factual changes. |
| 1:10–2:20 | Open the impact graph/list and inspect one exact source-to-asset evidence edge.        |
| 2:20–3:25 | Review, edit, and apply one patch with a clear consequence statement.                  |
| 3:25–4:10 | Show the new asset version/hash and deterministic verification checks.                 |
| 4:10–5:00 | Show Snowflake task history, benchmark/cost proof, and substantive CoCo evidence.      |

Required disclosure: “This demo uses disclosed prepared source snapshots so the same real Snowflake pipeline can be reproduced reliably without relying on external crawling or unsupported trial-account network access.”

Required claims remain deliberately narrow: validated evidence supports every confirmed edge; uncertainty stays uncertain; approval creates a new append-only asset version in one transaction; and deterministic checks—not LLM self-agreement—control verified status.
