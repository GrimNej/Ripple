# Cost ledger

## Guardrails

| Control | P0 limit |
|---|---:|
| Additional spend | USD 0 |
| Development AI admission cap | 2 AI credits/day |
| Demo reserve | At least 70% of remaining Snowflake balance |
| Initial warehouse monitor | 5 warehouse credits, where supported |
| Public unauthenticated AI | 0 calls |

Resource monitors govern warehouse usage only; Cortex and other serverless costs require separate usage queries and application admission controls.
